# AttendX-Test-Scripts

## Project Description
This repository contains sample automated tests
for the AttendX student attendance application.

## Test Scripts

1. login_test.py
   - Tests valid login.
   - Tests invalid password.

2. attendance_marking_test.py
   - Tests marking a student Present.
   - Tests invalid attendance status.

## Requirements
- Python 3
- Git

## How to Run

Run the login tests:

    python login_test.py

Run the attendance tests:

    python attendance_marking_test.py

## Version Control
Git is used to track changes, and GitHub is used
to share the test scripts with the QA team.

## Team Workflow
All QA engineers should commit their changes
and push them to the shared GitHub repository.
